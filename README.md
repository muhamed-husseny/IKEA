# IKEA — Full-Stack E-Commerce MVC Web Application

A full-stack e-commerce web application built with **ASP.NET Core MVC**[cite: 10], developed to facilitate complete end-to-end online shopping and catalog management workflows.

---

## Architecture 

Structured inside the `src` directory[cite: 10] following a clean, multi-layered architecture:

- **End-to-End Shopping Workflows:** Supports product browsing, category filtering, dynamic catalog management, and structured order processing.
- **Maintainable Backend Data Layer:** Architected using **C#**, **Entity Framework Core**, and the **Repository & Unit of Work** patterns for decoupled, optimized database operations.
- **Adaptive Frontend Interfaces:** Built with **Razor Views, Bootstrap, HTML5, CSS3, and JavaScript**[cite: 10] to ensure responsive, cross-device compatibility and an intuitive user experience.
- **Security & Access Control:** Integrated with **ASP.NET Core Identity** for user authentication, registration, and role-based dashboard management.

---

## Tech Stack

- **Backend:** C#, ASP.NET Core MVC[cite: 10]
- **Data Access & ORM:** Entity Framework Core, MS SQL Server, LINQ
- **Design Patterns:** Repository Pattern, Unit of Work, Dependency Injection, MVC
- **Frontend:** Razor Views, HTML5, CSS3[cite: 10], Bootstrap, JavaScript
